# Development Scripts

This folder contains development utilities and testing scripts. These are not included in the production Docker image.

## Files

- `deploy-clean.sh` - Automated deployment script for testing
- `test_mcp_server.sh` - Comprehensive endpoint testing
- `DEPLOYMENT_GUIDE.md` - Detailed deployment documentation

## Usage

These scripts are for developers and contributors. The main README.md contains the standard Docker deployment instructions.
